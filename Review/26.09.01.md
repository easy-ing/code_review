# 미로 탈출

## 1. 문제 유형

- **BFS (너비 우선 탐색)**
- 격자 최단거리 문제
- `S → L → E` 순서로 이동

---

## 2. 핵심 아이디어

레버를 반드시 먼저 당겨야 출구로 탈출할 수 있다.

따라서 문제를 두 개의 최단거리 문제로 나눈다.

```text
S → L → E

① S → L 최단거리
② L → E 최단거리

정답 = ① + ②
```

BFS는 한 칸 이동할 때마다 비용이 1이므로, 처음 목적지에 도착했을 때의 거리가 최단거리이다.

둘 중 하나라도 도달할 수 없다면 `-1`을 반환한다.

---

## 3. 시간복잡도

격자의 크기를 `N × M`이라고 하면,

- BFS 1회: `O(N × M)`
- BFS 2회: `O(N × M)`

따라서 전체 시간복잡도는

```text
O(N × M)
```

공간복잡도는 방문 배열과 큐 때문에

```text
O(N × M)
```

이다.

---

## 4. 코드

```python
from collections import deque


def solution(maps):
    n = len(maps)
    m = len(maps[0])

    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    # S, L, E 위치 찾기
    for i in range(n):
        for j in range(m):
            if maps[i][j] == 'S':
                start = (i, j)
            elif maps[i][j] == 'L':
                lever = (i, j)
            elif maps[i][j] == 'E':
                exit = (i, j)

    def bfs(start, target):
        queue = deque([(start[0], start[1], 0)])
        visited = [[False] * m for _ in range(n)]
        visited[start[0]][start[1]] = True

        while queue:
            x, y, distance = queue.popleft()

            if (x, y) == target:
                return distance

            for dx, dy in directions:
                nx = x + dx
                ny = y + dy

                if 0 <= nx < n and 0 <= ny < m:
                    if maps[nx][ny] != 'X' and not visited[nx][ny]:
                        visited[nx][ny] = True
                        queue.append((nx, ny, distance + 1))

        return -1

    # S → L
    to_lever = bfs(start, lever)

    if to_lever == -1:
        return -1

    # L → E
    to_exit = bfs(lever, exit)

    if to_exit == -1:
        return -1

    return to_lever + to_exit
```

---

## 5. 총평

`S → L → E`로 이동해야 한다는 조건 때문에 BFS를 **두 번 나눠서 실행**하면 쉽게 해결할 수 있다.

핵심은 **레버를 기준으로 경로를 두 구간으로 분리하는 것**이다.

```text
S ─────→ L ─────→ E
   BFS ①     BFS ②
```

각 구간의 최단거리를 구한 뒤 더하면 전체 최소 이동 시간이 된다.
