# **📌 삼총사 (Two-pointer 최적화)**

**문제 유형**

완전탐색, 투포인터, 정렬

---

### 원래 풀이 (브루트포스)

```python
def solution(number):
    answer = 0
    n = len(number)

    for i in range(n):
        for j in range(i + 1, n):
            for k in range(j + 1, n):
                if number[i] + number[j] + number[k] == 0:
                    answer += 1

    return answer
```

---

### 최적화된 풀이 (정렬 + 투포인터, O(N^2))

```python
def solution(number):
    number.sort()
    n = len(number)
    count = 0

    for i in range(n - 2):
        left = i + 1
        right = n - 1
        while left < right:
            s = number[i] + number[left] + number[right]
            if s == 0:
                if number[left] == number[right]:
                    m = right - left + 1
                    count += m * (m - 1) // 2
                    break
                else:
                    cntL = 1
                    cntR = 1
                    while left + 1 < right and number[left] == number[left + 1]:
                        cntL += 1
                        left += 1
                    while right - 1 > left and number[right] == number[right - 1]:
                        cntR += 1
                        right -= 1
                    count += cntL * cntR
                    left += 1
                    right -= 1
            elif s < 0:
                left += 1
            else:
                right -= 1

    return count
```

---

## **핵심 아이디어(비교)**

- 원래 풀이: 세 중첩 루프를 사용해 모든 조합을 확인하므로 O(N^3) 시간복잡도를 가집니다.
- 최적화: 배열을 정렬한 뒤, 첫 번째 포인터를 고정하고 나머지 두 포인터를 투포인터로 탐색하면 O(N^2)으로 개선됩니다.

---

## **시간 복잡도 비교**

- 원래: O(N^3)
- 최적화: O(N^2)

---

## **총평**

정렬 후 투포인터를 사용하면 중복 값들을 효율적으로 처리할 수 있어 큰 입력에서도 충분히 빠르게 동작합니다. 이 방법은 조합 기반의 브루트포스를 상당히 줄여줍니다.
