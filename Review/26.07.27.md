# **📌 신규 아이디 추천**

**문제 유형**

문자열 구현

---

### 코드

```python
def solution(new_id):
    # 1단계: 대문자를 소문자로 변경
    new_id = new_id.lower()

    # 2단계: 허용된 문자만 남기기
    allowed = "abcdefghijklmnopqrstuvwxyz0123456789-_."
    new_id = "".join(char for char in new_id if char in allowed)

    # 3단계: 연속된 마침표를 하나로 변경
    while ".." in new_id:
        new_id = new_id.replace("..", ".")

    # 4단계: 처음과 끝의 마침표 제거
    new_id = new_id.strip(".")

    # 5단계: 빈 문자열이면 "a" 대입
    if not new_id:
        new_id = "a"

    # 6단계: 길이가 16 이상이면 15자까지만 자르기
    new_id = new_id[:15]

    # 자른 뒤 마지막 문자가 마침표라면 제거
    new_id = new_id.rstrip(".")

    # 7단계: 길이가 3이 될 때까지 마지막 문자 붙이기
    while len(new_id) < 3:
        new_id += new_id[-1]

    return new_id
```

---

## **핵심 아이디어**

이 문제는 **문자열 구현 문제**로, 문제에서 제시한 **7단계를 순서대로 그대로 구현**하면 됩니다.

각 단계의 결과가 다음 단계의 입력이 되므로 **처리 순서를 바꾸면 안 됩니다.**

- `lower()`로 모든 문자를 소문자로 변환
- 허용된 문자(`a-z`, `0-9`, , `_`, `.`)만 남기기
- 연속된 `.`을 하나의 `.`으로 변경
- 문자열의 처음과 끝에 있는 `.` 제거
- 빈 문자열이면 `"a"` 대입
- 길이가 15자를 초과하면 잘라내고 마지막 `.` 제거
- 길이가 3보다 짧으면 마지막 문자를 반복해서 붙이기

---

## **시간 복잡도**

문자열의 길이를 **N**이라 하면 대부분의 단계는 문자열을 한 번씩만 순회하므로 **O(N)**입니다.

3단계에서 `replace()`를 반복 사용하기 때문에 최악의 경우 **O(N²)**까지 될 수 있지만, 문자열 길이가 최대 **1000**이므로 충분히 통과합니다.

(정규표현식을 사용하면 3단계도 O(N)에 처리할 수 있습니다.)

## **총평**

대표적인 **문자열 구현 문제**입니다.

어려운 알고리즘보다는 **문제를 꼼꼼히 읽고 조건을 빠짐없이 구현하는 능력**을 묻는 문제입니다.

실수하기 쉬운 부분은 다음 세 가지입니다.

- 15자로 자른 뒤 **마지막 `.`을 한 번 더 제거해야 하는 것**
- 빈 문자열을 `"a"`로 바꾼 후 다음 단계를 진행하는 것
- 길이가 3이 될 때까지 **마지막 문자를 반복해서 붙이는 것**

조건을 순서대로 차근차근 구현하면 어렵지 않게 해결할 수 있는 문제입니다.
