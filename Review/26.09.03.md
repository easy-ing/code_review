1. 문제 유형

수학 / 최대공약수(GCD)

한 배열의 모든 원소를 나눌 수 있는 가장 큰 수를 찾고, 그 수가 다른 배열의 어떤 원소도 나누지 못하는지 확인하는 문제이다.

핵심은 모든 원소의 공약수 중 가장 큰 수는 GCD라는 점이다.

⸻

2. 핵심 아이디어

Step 1. 각 배열의 GCD를 구한다.

gcdA = reduce(gcd, arrayA)
gcdB = reduce(gcd, arrayB)

gcdA는 arrayA의 모든 원소를 나눌 수 있는 수 중 가장 큰 수이다.

마찬가지로 gcdB는 arrayB의 모든 원소를 나눌 수 있는 가장 큰 수이다.

⸻

Step 2. gcdA가 조건을 만족하는지 확인한다.

if all(b % gcdA != 0 for b in arrayB):
    answer = max(answer, gcdA)

gcdA는 이미 arrayA의 모든 숫자를 나눌 수 있다.

따라서 arrayB의 숫자 중 하나라도 gcdA로 나누어진다면 조건을 만족하지 못한다.

반대로 arrayB의 모든 숫자가 gcdA로 나누어지지 않는다면 gcdA는 조건을 만족한다.

⸻

Step 3. 반대 경우도 동일하게 확인한다.

if all(a % gcdB != 0 for a in arrayA):
    answer = max(answer, gcdB)

gcdB가 arrayA의 어떤 숫자도 나누지 못한다면 조건을 만족한다.

⸻

Step 4. 두 후보 중 큰 값을 반환한다.

return answer

둘 다 조건을 만족하지 않는다면 answer는 초기값인 0이므로 0을 반환한다.

⸻

3. 구현 코드

from math import gcd
from functools import reduce
def solution(arrayA, arrayB):
    gcdA = reduce(gcd, arrayA)
    gcdB = reduce(gcd, arrayB)
    answer = 0
    # arrayA의 모든 원소를 나누는 gcdA가
    # arrayB의 어떤 원소도 나누지 못하는지 확인
    if all(b % gcdA != 0 for b in arrayB):
        answer = max(answer, gcdA)
    # arrayB의 모든 원소를 나누는 gcdB가
    # arrayA의 어떤 원소도 나누지 못하는지 확인
    if all(a % gcdB != 0 for a in arrayA):
        answer = max(answer, gcdB)
    return answer

⸻

4. 코드 리뷰

reduce(gcd, arrayA)

gcdA = reduce(gcd, arrayA)

여러 숫자의 GCD를 한 번에 구하기 위해 reduce()를 사용했다.

예를 들어:

arrayA = [14, 35, 119]

이라면 내부적으로

gcd(14, 35) = 7
gcd(7, 119) = 7

순서로 계산되어 최종적으로 7이 나온다.

⸻

all()을 활용한 조건 검사

all(b % gcdA != 0 for b in arrayB)

arrayB의 모든 원소가 gcdA로 나누어 떨어지지 않는지를 확인한다.

예를 들어:

gcdA = 7
arrayB = [18, 30, 102]

이면

18 % 7 != 0
30 % 7 != 0
102 % 7 != 0

이므로 all()은 True를 반환한다.

⸻

5. 왜 GCD만 확인하면 되는가?

이 문제의 핵심이다.

arrayA의 모든 숫자를 나눌 수 있는 수는 반드시 gcdA의 약수이다.

예를 들어:

arrayA = [24, 36, 60]
gcdA = 12

라면 arrayA의 모든 숫자를 나눌 수 있는 수는

1, 2, 3, 4, 6, 12

이다.

이 중 가장 큰 수는 12이다.

따라서 12가 조건을 만족한다면 당연히 정답 후보가 된다.

반대로 12가 arrayB의 어떤 원소를 나눈다면, 12의 약수들도 그 원소를 나눌 가능성이 있으므로 arrayA 쪽에서는 조건을 만족하는 더 큰 후보를 찾을 수 없다.

즉,

한 배열의 모든 숫자를 나눌 수 있는 가장 큰 후보는 해당 배열의 GCD뿐이다.

따라서 gcdA, gcdB 두 값만 검사하면 충분하다.

⸻

6. 예제 분석

arrayA = [14, 35, 119]
arrayB = [18, 30, 102]

arrayA의 GCD

gcd(14, 35, 119) = 7

arrayB 확인:

18 % 7 != 0
30 % 7 != 0
102 % 7 != 0

따라서 7은 후보이다.

⸻

arrayB의 GCD

gcd(18, 30, 102) = 6

arrayA 확인:

14 % 6 != 0
35 % 6 != 0
119 % 6 != 0

따라서 6도 후보이다.

⸻

최종 결과

max(7, 6) = 7

따라서 정답은 7이다.

⸻

7. 시간 복잡도

배열의 길이를 N, 원소의 최대값을 M이라고 하면,

GCD 계산은 유클리드 알고리즘을 사용하므로

O(N log M)

이다.

두 배열의 조건 확인은 각각 O(N)이므로 전체 시간 복잡도는

O(N log M)

이다.

공간 복잡도는 추가 배열을 사용하지 않으므로

O(1)

이다.

⸻

8. 총평

이 문제는 GCD를 이용하면 완전탐색을 피할 수 있는 문제이다.

처음에는 1 ~ 100,000,000 중 조건을 만족하는 숫자를 찾아야 할 것처럼 보이지만,

arrayA의 모든 원소를 나눌 수 있는 가장 큰 수
        ↓
arrayA의 GCD
arrayB의 모든 원소를 나눌 수 있는 가장 큰 수
        ↓
arrayB의 GCD

로 후보를 단 두 개로 줄일 수 있다.

핵심 한 줄

각 배열의 GCD를 구한 뒤, 그 GCD가 상대 배열의 어떤 원소도 나누지 못하는지 검사하고 둘 중 큰 값을 선택한다.
