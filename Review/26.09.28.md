# 석유 시추 - 코드리뷰

## 1. 문제 유형

- **BFS / DFS**
- **그래프 탐색**
- **컴포넌트(연결된 덩어리) 탐색**
- **열별 누적 합**

---

## 2. 문제 핵심

이 문제에서 중요한 점은 **시추관이 지나간 칸의 석유만 가져가는 것이 아니라, 해당 칸이 포함된 석유 덩어리 전체를 가져간다**는 것입니다.

예를 들어 하나의 석유 덩어리가 다음처럼 생겼다고 하면:

```text
0 1 1 0
0 0 1 0
0 1 1 1
```

이 덩어리의 크기가 5이고 2, 3, 4번 열에 걸쳐 있다면,

```text
2번 열 → +5
3번 열 → +5
4번 열 → +5
```

를 해주면 됩니다.

따라서 문제를 다음 두 단계로 나눌 수 있습니다.

1. BFS/DFS로 석유 덩어리를 하나씩 찾는다.
2. 찾은 덩어리의 크기를 그 덩어리가 포함된 모든 열에 더한다.

---

## 3. 풀이 아이디어

### 잘못 생각하기 쉬운 방법

각 열마다 시추관을 뚫고 BFS를 수행하는 방법을 생각할 수 있습니다.

```text
1번 열 → BFS
2번 열 → BFS
3번 열 → BFS
...
m번 열 → BFS
```

하지만 `n, m <= 500`이므로 최대 `250,000`개의 칸이 있습니다.

각 열마다 전체 땅을 다시 탐색하면 같은 칸을 여러 번 방문하게 되어 효율성 테스트에서 불리합니다.

---

### 올바른 방법

반대로 생각합니다.

**"시추관을 기준으로 덩어리를 찾는 것"이 아니라 "덩어리를 먼저 찾고, 그 덩어리가 영향을 주는 열을 기록한다."**

예를 들어 덩어리 하나를 BFS로 탐색하면서:

```python
size = 0
columns = set()
```

을 사용합니다.

BFS로 석유 칸을 하나 발견할 때마다:

```python
size += 1
columns.add(y)
```

를 수행합니다.

BFS가 끝나면:

- `size` = 해당 석유 덩어리의 크기
- `columns` = 해당 덩어리가 걸쳐 있는 열

이 됩니다.

그 후:

```python
for col in columns:
    oil[col] += size
```

를 수행합니다.

---

## 4. 코드

```python
from collections import deque

def solution(land):
    n = len(land)
    m = len(land[0])

    # 각 열에서 얻을 수 있는 석유량
    oil = [0] * m

    # 상, 하, 좌, 우
    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    # 모든 석유 덩어리를 한 번씩만 탐색
    for r in range(n):
        for c in range(m):

            if land[r][c] == 0:
                continue

            # 하나의 석유 덩어리 탐색
            queue = deque([(r, c)])
            land[r][c] = 0

            size = 0
            columns = set()

            while queue:
                x, y = queue.popleft()

                size += 1
                columns.add(y)

                for dx, dy in directions:
                    nx = x + dx
                    ny = y + dy

                    if 0 <= nx < n and 0 <= ny < m:
                        if land[nx][ny] == 1:
                            land[nx][ny] = 0
                            queue.append((nx, ny))

            # 이 덩어리가 걸쳐 있는 모든 열에 크기를 더함
            for col in columns:
                oil[col] += size

    return max(oil)
```

# 5. 코드 리뷰

## 5-1. `oil` 배열

```python
oil = [0] * m
```

각 열에서 얻을 수 있는 석유량을 저장합니다.

예를 들어:

```text
oil = [8, 8, 8, 7, 7, 7, 9, 2]
```

라면,

```text
1번 열 → 8
2번 열 → 8
...
7번 열 → 9
8번 열 → 2
```

라는 의미입니다.

마지막에:

```python
return max(oil)
```

을 하면 가장 많은 석유를 얻을 수 있는 열의 값을 구할 수 있습니다.

---

## 5-2. BFS 시작 조건

```python
for r in range(n):
    for c in range(m):

        if land[r][c] == 0:
            continue
```

모든 칸을 확인하면서 아직 방문하지 않은 석유 칸을 찾습니다.

이미 방문한 석유는 BFS를 시작할 때:

```python
land[r][c] = 0
```

으로 바꿔주기 때문에 다시 탐색하지 않습니다.

즉, `land` 자체를 방문 배열처럼 사용합니다.

---

## 5-3. 하나의 덩어리 탐색

```python
queue = deque([(r, c)])
land[r][c] = 0

size = 0
columns = set()
```

여기서 새로운 석유 덩어리 하나를 탐색하기 시작합니다.

### `size`

```python
size = 0
```

현재 덩어리에 포함된 석유 칸의 개수입니다.

### `columns`

```python
columns = set()
```

현재 덩어리가 걸쳐 있는 열을 저장합니다.

`set`을 사용하는 이유는 같은 열에 석유 칸이 여러 개 있어도 한 번만 기록해야 하기 때문입니다.

예를 들어:

```text
1 1
1 1
1 0
```

이라면 1번 열에 석유가 3칸 있지만, 열 자체는 **1번 열 하나**입니다.

따라서:

```python
columns = {0}
```

처럼 저장합니다.

---

## 5-4. BFS에서 덩어리 크기 계산

```python
while queue:
    x, y = queue.popleft()

    size += 1
    columns.add(y)
```

BFS에서 하나의 석유 칸을 꺼낼 때마다:

```python
size += 1
```

하여 덩어리 크기를 증가시킵니다.

그리고:

```python
columns.add(y)
```

를 통해 해당 석유 칸이 존재하는 열을 기록합니다.

---

## 5-5. 상하좌우 탐색

```python
for dx, dy in directions:
    nx = x + dx
    ny = y + dy
```

현재 칸에서 상하좌우로 이동합니다.

```python
directions = [
    (1, 0),
    (-1, 0),
    (0, 1),
    (0, -1)
]
```

각각:

```text
(1, 0)  → 아래
(-1, 0) → 위
(0, 1)  → 오른쪽
(0, -1) → 왼쪽
```

입니다.

---

## 5-6. 방문하지 않은 석유만 큐에 추가

```python
if 0 <= nx < n and 0 <= ny < m:
    if land[nx][ny] == 1:
        land[nx][ny] = 0
        queue.append((nx, ny))
```

범위를 벗어나지 않았고 석유가 있다면 BFS에 추가합니다.

여기서 중요한 부분은:

```python
land[nx][ny] = 0
```

을 **큐에 넣는 순간** 처리한다는 것입니다.

이렇게 해야 같은 칸이 여러 번 큐에 들어가는 것을 방지할 수 있습니다.

---

# 6. 덩어리 탐색이 끝난 후

BFS가 끝났다는 것은 하나의 석유 덩어리를 전부 찾았다는 의미입니다.

예를 들어:

```python
size = 7
columns = {3, 4, 5}
```

라면 크기가 7인 덩어리가 4, 5, 6번째 열에 걸쳐 있다는 뜻입니다.

따라서:

```python
for col in columns:
    oil[col] += size
```

를 수행합니다.

결과:

```text
4번 열 → +7
5번 열 → +7
6번 열 → +7
```

이 됩니다.

---

# 7. 왜 `set`이 중요한가?

`columns`를 단순한 리스트로 만들면 같은 열이 여러 번 들어갈 수 있습니다.

예를 들어 하나의 덩어리가:

```text
0 1
0 1
0 1
```

처럼 생겼다면 2번째 열이 세 번 등장합니다.

리스트라면:

```python
columns = [1, 1, 1]
```

이 되고,

```python
for col in columns:
    oil[col] += size
```

를 하면 같은 덩어리 크기를 세 번 더하게 됩니다.

반면 `set`은:

```python
columns = {1}
```

이므로 정확하게 한 번만 더할 수 있습니다.

# 8. 전체 동작 예시

첫 번째 예제에서 석유 덩어리가 다음과 같이 있다고 생각해 봅시다.

```text
덩어리 A → 크기 8 → 1, 2, 3번 열
덩어리 B → 크기 7 → 4, 5, 6, 7번 열
덩어리 C → 크기 2 → 7, 8번 열
```

각 덩어리를 처리하면:

```text
A:
oil[1] += 8
oil[2] += 8
oil[3] += 8

B:
oil[4] += 7
oil[5] += 7
oil[6] += 7
oil[7] += 7

C:
oil[7] += 2
oil[8] += 2
```

최종적으로:

```text
[8, 8, 8, 7, 7, 7, 9, 2]
```

가 됩니다.

따라서:

```python
max(oil)
```

은:

```text
9
```

를 반환합니다.

---

# 9. 시간복잡도

전체 격자의 크기를 `N = n × m`이라고 하겠습니다.

각 석유 칸은 BFS에서 한 번만 방문합니다.

따라서 BFS 자체는:

```text
O(n × m)
```

입니다.

각 덩어리마다 해당 덩어리가 차지하는 열을 한 번씩 확인하는 작업도 전체적으로 각 석유 칸 수를 넘지 않습니다.

따라서 전체 시간복잡도는:

```text
O(n × m)
```

수준입니다.

최대 크기:

```text
500 × 500 = 250,000칸
```

이므로 충분히 처리할 수 있습니다.

공간복잡도는 BFS 큐와 `columns` 등을 고려하여:

```text
O(n × m)
```

입니다.

# 10. 코드리뷰 총평

### 잘한 점

- 석유 덩어리를 BFS로 한 번씩만 탐색했다.
- 방문한 칸을 `0`으로 변경하여 별도의 `visited` 배열을 만들지 않았다.
- 덩어리의 크기와 해당 덩어리가 걸쳐 있는 열을 동시에 구했다.
- `set`을 사용하여 같은 열에 덩어리 크기를 중복해서 더하지 않았다.
- 마지막에 열별 누적값 중 `max()`를 구해 답을 얻었다.

### 이 문제에서 가장 중요한 사고방식

처음에는 보통:

```text
시추관 1번 → 석유 찾기
시추관 2번 → 석유 찾기
시추관 3번 → 석유 찾기
...
```

라고 생각하기 쉽습니다.

하지만 효율적인 풀이는 반대입니다.

```text
석유 덩어리 1개 찾기
        ↓
덩어리 크기 계산
        ↓
덩어리가 걸쳐 있는 열 기록
        ↓
해당 열들에 덩어리 크기 더하기
```

즉,

> **"시추관 기준으로 탐색하지 말고, 석유 덩어리를 먼저 찾아서 각 열에 영향력을 누적한다."**

가 이 문제의 핵심입니다.
