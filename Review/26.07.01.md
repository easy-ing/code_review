### 원래 풀이 (정렬 사용)

```python
def solution(k, score):
    answer = []
    hall = []

    for s in score:
        hall.append(s)
        hall.sort(reverse=True)

        if len(hall) > k:
            hall.pop()

        answer.append(hall[-1])

    return answer
```

---

### 최적화된 풀이 (최소힙 사용, O(N log k))

```python
import heapq


def solution(k, score):
    heap = []
    answer = []

    for s in score:
        heapq.heappush(heap, s)
        if len(heap) > k:
            heapq.heappop(heap)
        answer.append(heap[0])

    return answer
```

---

## **핵심 아이디어(비교)**

- 원래 풀이: 매번 명예의 전당 리스트를 정렬하므로 불필요한 정렬 비용이 발생합니다. 특히 k가 작을 때 정렬 비용이 커집니다.
- 최적화: 최소 힙을 사용하면 힙의 크기를 k로 유지하면서 새로운 점수를 삽입/삭제하는 연산이 O(log k)로 줄어듭니다. 전체 시간 복잡도는 O(N log k)입니다.

---

## **시간 복잡도 비교**

- 원래: 각 삽입/정렬에 O(k log k) (또는 O(k log k)로 가정) → 전체 O(N * k log k)
- 최적화: 각 삽입/팝이 O(log k) → 전체 O(N log k)

---

## **총평**

- 입력 크기나 k의 크기에 따라 최적화 효과가 큽니다. 특히 N이 크고 k가 상대적으로 작은 경우 힙 기반 풀이가 더 효율적입니다.
