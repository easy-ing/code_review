# **📌**  **K진수에서 소수 개수 구하기**

문제 유형

- 구현(Implementation)
- 문자열(String)
- 진법 변환(Base Conversion)
- 수학(Math)
- 소수 판별(Prime Number)

---

### 코드

```python
import math

def solution(n, k):
    # k진수 변환
    def convert(num):
        if num == 0:
            return "0"

        result = ""
        while num > 0:
            result = str(num % k) + result
            num //= k

        return result

    # 소수 판별
    def is_prime(num):
        if num < 2:
            return False

        for i in range(2, int(math.sqrt(num)) + 1):
            if num % i == 0:
                return False

        return True

    converted = convert(n)
    answer = 0

    for num in converted.split("0"):
        if num and is_prime(int(num)):
            answer += 1

    return answer
```

---

## **핵심 아이디어**

- 주어진 정수를 **k진수 문자열**로 변환한다.
- 변환된 문자열을 **`0`을 기준으로 분리**하면 문제에서 조건을 만족하는 후보 숫자들을 얻을 수 있다.
- 빈 문자열을 제외한 각 문자열을 **10진수 정수**로 변환한 뒤 소수 여부를 판별한다.
- 소수인 경우 개수를 증가시키고 최종 개수를 반환한다.

---

## **시간 복잡도**

- **진법 변환** : `O(logₖN)`
- **문자열 분리** : `O(L)` (`L`은 k진수 문자열의 길이)
- **소수 판별** : 각 숫자마다 `O(√M)` (`M`은 분리된 숫자의 크기)

전체 시간 복잡도는 O(L + Σ√M)이다.

---

## **총평**

이 문제는 **진법 변환 → 문자열 처리 → 소수 판별**의 세 과정을 차례대로 구현하는 문제이다. 핵심은 `0`을 기준으로 문자열을 분리하여 소수 후보를 추출하는 것이며, 분리된 문자열은 **k진수가 아닌 10진수 숫자**로 해석해야 한다는 점을 주의해야 한다. 또한 소수 판별은 `√N`까지만 확인하여 불필요한 연산을 줄이는 것이 중요하다.
