# **📌**  **[PCCP 기출문제] 1번 / 붕대 감기**

**문제 유형**

구현, 시뮬레이션

---

### 코드

```python
def solution(bandage, health, attacks):
    t, x, y = bandage

    hp = health          # 현재 체력
    combo = 0            # 연속 성공 횟수

    attack_idx = 0
    last_time = attacks[-1][0]

    for time in range(1, last_time + 1):

        # 공격 시간인 경우
        if attack_idx < len(attacks) and time == attacks[attack_idx][0]:
            hp -= attacks[attack_idx][1]

            if hp <= 0:
                return -1

            combo = 0
            attack_idx += 1

        # 공격이 없는 경우
        else:
            combo += 1
            hp = min(health, hp + x)

            if combo == t:
                hp = min(health, hp + y)
                combo = 0

    return hp
```

---

## **핵심 아이디어**

- 마지막 공격 시간까지 **1초씩 순회**하며 현재 상태를 갱신합니다.
- 현재 시간이 공격 시간이라면
    - 체력을 감소시키고,
    - 체력이 0 이하이면 즉시 `1`을 반환합니다.
    - 붕대 감기가 취소되므로 연속 성공 횟수를 `0`으로 초기화합니다.
- 공격이 없는 시간이라면
    - 초당 회복량만큼 체력을 회복합니다.
    - 연속 성공 횟수를 증가시키고,
    - 연속 성공 시간이 `t`에 도달하면 추가 회복을 적용한 뒤 연속 성공 횟수를 다시 `0`으로 초기화합니다.
- 회복 시에는 항상 `min(현재 체력, 최대 체력)`을 이용하여 최대 체력을 초과하지 않도록 처리합니다.

---

## **시간 복잡도**

- 마지막 공격 시간(`T`)까지 1초씩 순회하므로 **O(T)**
- 문제의 제한에서 `T ≤ 1000`이므로 충분히 효율적입니다.

---

## **총평**

시간이 최대 1000초로 매우 작기 때문에 복잡한 최적화보다는 **정확한 시뮬레이션**이 가장 적합한 문제입니다. 구현 과정에서 **공격 시간에는 회복이 이루어지지 않는 점**, **추가 회복 후 연속 성공 횟수를 초기화하는 점**, **최대 체력을 넘지 않도록 처리하는 점**을 놓치지 않는 것이 가장 중요합니다. 이러한 조건만 정확히 구현하면 무난하게 해결할 수 있는 구현 문제입니다.
